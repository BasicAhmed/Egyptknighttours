# Phase 4 – Design system (from the Egypt Knight logo)

Logo: black Anubis-style knight with gold accents over a golden pyramid, gold wordmark plate, black type.
Sampled dominant colors: black `#000000`, gold `#F0B050`, deep gold `#C09040`.

## Tokens
| Token | Value | Use |
|---|---|---|
| ink | `#141010` | text, dark sections, header |
| gold-500 (primary) | `#F0B050` | primary buttons, highlights |
| gold-700 | `#C09040` | hover, borders, icons |
| sand-100 | `#FBF4E6` | page background |
| sand-200 | `#F3E6C8` | cards, sections |
| white | `#FFFFFF` | surfaces |
| nile (accent) | `#1F6F78` | links, info, secondary CTA (used sparingly) |
| success / danger | `#2E7D4F` / `#B3261E` | status |
Contrast: ink on gold and ink on sand pass AA; never white text on gold.

## Type
Headings: a friendly bold display sans (e.g. Sora or Bricolage Grotesque). Body: Inter. Arabic-ready pairing: IBM Plex Sans Arabic. Self-hosted, `font-display: swap`.

## Components
Radius 12px cards / 999px pills. Soft warm shadows (`0 6px 20px rgba(20,16,16,.08)`). Buttons: primary gold with ink text, secondary ink outline, WhatsApp green only for the WhatsApp CTA. Badges: Private, Family friendly, Free cancellation (only when true). Sticky bottom bar on mobile with price + Book + WhatsApp. Hover: 2px lift, no heavy animation.

## Mascot use
Header logo, 404 page, empty states, trip builder guide, and footer only. No hieroglyph patterns, no gold textures.
